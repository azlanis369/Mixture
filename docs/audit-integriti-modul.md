# Audit Integriti — Modul, Ciri & Fungsi RENFlow Plus

> **Peraturan emas:** Setiap dakwaan **Live** di landing page MESTI benar-benar
> berfungsi di enjin (diakses via `app.renflowplus.com`) — boleh guna tanpa
> masalah, tanpa eksperimen. Kalau tak benar-benar sedia → **turunkan label**
> sebelum halakan pelanggan berbayar ke situ.
>
> Nota: pembina landing page (repo ini) **tiada akses ke enjin superren.group**,
> jadi pengesahan setiap baris di bawah adalah tanggungjawab admin/owner.
> Tandakan setiap satu, dan kami laraskan label supaya padan realiti.

## Cara guna
1. Untuk setiap modul **Live**, buka enjin dan uji sendiri.
2. Tanya: *"Boleh guna sekarang, tanpa masalah, tanpa 'ini eksperimen'?"*
3. Tanda `[x]` = benar-benar berfungsi. Biar kosong `[ ]` = belum.
4. Mana-mana yang belum → beritahu, kami turunkan ke **Draft/Beta** atau **Roadmap**.

---

## A. Modul berlabel LIVE (perlu 100% terbukti)

- [ ] **Public Profile** — profile premium boleh dikongsi via QR/link, betul-betul render & shareable
- [ ] **Listing Manager** — boleh tambah/susun listing ikut unit
- [ ] **Media Board** — gambar tersusun ikut listing
- [ ] **Lead Capture** — enquiry & form lead direkod automatik dengan sumber
- [ ] **Mini CRM** — status, nota, next action per lead
- [ ] **Deal Pipeline** — track booking → loan → closed
- [ ] **QR Card** — kad digital scan terus ke public profile
- [ ] **Basic Analytics** — profile views, listing clicks, WA clicks (angka sebenar)
- [ ] **Commission Tracker** — pantau komisen per deal, tersambung Deal Pipeline
- [ ] **WhatsApp Integration** — balas/chat lead dari CRM, perbualan tersimpan pada profile
- [ ] **Automated Follow-ups** — reminder & sequence automatik selepas enquiry/meeting/demo

## B. Modul berlabel DRAFT/BETA (boleh guna, sedang diperhalusi)

- [ ] **Caption Studio** — jana caption WA/TG/FB, semak & hantar sendiri
- [ ] **Autobot** — bantu draf respons (bukan auto-posting rasmi)

> Kalau salah satu ini sebenarnya **belum boleh guna langsung**, beritahu —
> kami tukar ke Roadmap. Kalau dah **stabil sepenuhnya**, boleh naik ke Live.

## C. Modul berlabel ROADMAP (belum, tertakluk API pihak ketiga)

- **Meta Lead Integration** — tarik lead dari Meta Ads (perlu kelulusan API Meta)
- **Meet & Zoom** — jadual meeting dari CRM (perlu OAuth Google/Zoom)

> Kekal Roadmap sehingga integrasi rasmi diluluskan. Jangan naik ke Live tanpa
> kelulusan API — itu risiko undang-undang & kepercayaan.

## D. Dakwaan lain di landing page (perlu padan realiti)

- [ ] **ProfilePreview** (seksyen "Apa prospect nampak") — pipeline stages
      (Enquiry→Viewing→Booking→Loan→Closed) & Quick Stats wujud dalam enjin

      dijana dari data sebenar (bukan angka rekaan)

> Nota: seksyen Proof sekarang guna **diagram struktur**, bukan angka rekaan
> (ikut guardrail). Bila ada screenshot dashboard sebenar → ganti.

---

## E. Prinsip kekal

1. **Jangan halakan pelanggan berbayar ke ciri yang belum benar-benar berfungsi.**
2. Label mesti padan realiti enjin, bukan aspirasi.
3. Yang bergantung pada kelulusan pihak ketiga (Meta/Google/Zoom/WA Business API
   rasmi) = kekal Roadmap sehingga diluluskan.
4. Bila status berubah di enjin → kemas kini label di landing page serta-merta.
